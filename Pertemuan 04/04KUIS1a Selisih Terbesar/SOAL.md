<h1 align="center">04KUIS1a. Selisih Terbesar</h1>
<p align="center">
<b>Time limit:</b> 500 ms<br><b>Memory limit:</b> 26214 KB
</p>

### Description
Terdapat N bilangan bulat yang masing-masing dilambangkan dengan A_i. Ingin diketahui selisih terbesar dari dua bilangan yang bersebelahan. Sebagai contoh, jika terdapat 5 bilangan {5, 8, 9, 1, 4} maka selisih terbesar adalah 8, yaitu selisih antara bilangan 9 dan 1. Selisih semua dua bilangan yang bersebelahan adalah {3, 1, 8, 3}.

Buatlah program untuk menentukan selisih terbesar dari dua bilangan yang bersebelahan tersebut.

### Constraints
- 1≤N≤10000
- 1≤A_i≤2 milyar

### Input Format
Input data diberikan dengan format sebagai berikut:
```txt
N
A_1 A_2 ... A_N
```

### Output Format
Sebuah bilangan bulat yang menunjukkan selisih terbesar dari dua bilangan yang bersebelahan.

### Sample Input
```txt
5
5 8 9 1 4
```

### Sample Output
```txt
8
```
