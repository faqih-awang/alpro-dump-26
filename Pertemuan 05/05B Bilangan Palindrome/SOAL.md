<h1 align="center">05B. Bilangan Palindrome</h1>
<p align="center">
<b>Time limit:</b> 500 ms<br><b>Memory limit:</b> 64 MB
</p>

### Description
Palindrome adalah kata, rangkaian kata, atau bilangan yang terbaca sama baik dari depan maupun dari belakang. Dengan kata lain, palindrome adalah suatu kata, frasa, angka, maupun susunan lainnya yang apabila dibaca dari depan maupun belakang akan memiliki bunyi yang sama. Sebagai contoh, bilangan 232 adalah palindrome, sedangkan 234 adalah bukan palindrome.<br>
Buatlah program untuk membaca n bilangan bulat, dan periksalah apakah setiap bilangan tersebut merupakan palindrome atau bukan.

### Input Format
Baris pertama adalah n (1≤n≤5000) yang menunjukkan banyaknya bilangan yang akan diperiksa. Baris-baris berikutnya sebanyak n bilangan bulat positif.

### Output Format
Sebanyak n baris hasil pemeriksaan bilangan. Jika palindrome, tuliskan angka 1, sebaliknya tuliskan angka 0.

### Sample Input
```txt
5
2334332
555
1234
50
123
```

### Sample Output
```txt
1
1
0
0
0
```
