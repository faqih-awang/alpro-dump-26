<b>Time limit:</b> 2 s<br><b>Memory limit:</b> 64 MB

### Description
Sekarang Anda akan belajar menulis menggunakan program. Pada soal ini Anda diminta untuk membuat program sederhana yang mencetak suatu teks di layar. Teks yang akan dicetak dapat dilihat pada bagian Sample Output.

Untuk membantu Anda, Anda dapat melihat dokumentasi bahasa C terkait fungsi [printf](https://devdocs.io/c/io/fprintf) untuk mencetak serta [escape sequence](https://devdocs.io/c/language/escape). 

### Input Format
Tidak ada input pada problem ini.

### Output Format
Teks seperti yang terlampir di bawah ini. Akhiri setiap baris dengan karakter newline ('\n').

### Sample Input
```txt
-
```

### Sample Output
```txt
"Kampus Terbaik"
Kampus terbaik, inovasi wujudkan impian
Kampus terbaik, integritas kuatkan tujuan
Kampus terbaik beri terbaik untuk negeri,
Untuk dunia
Umat manusia dan alam semesta
```
